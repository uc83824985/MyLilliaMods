# LilliaChasePrototype 0.1.9

本地追逐玩法实验：新增 [白盒追逐实验室](sim/chase-lab/README.md)，支持回字／田字地图、随机出刀、玩家能力与倾向、暴露度、后台批量模拟、参数搜索、回放和玩家接管。该实验框架独立于插件；0.1.4 游戏侧已同步当前 `rhythm-mixed` 的轻重刀与闪避，搜索、疲劳和其他技能仍各自独立。

独立 BepInEx IL2CPP 插件，实现第一轮警察抓捕与主角基础闪避原型。源码、配置、Harmony ID 和运行状态均独立，不引用或复制加载 LilliaSystem 程序集。已有六份玩法文档仍是后续扩展规格，本插件只实现抓捕和基础闪避。

## 使用

- **Space**：消耗体力，按当前移动方向闪避；没有方向输入时按主角朝向突进。
- **F6**：独立参数面板，按分组修改后点击“应用并保存”。关闭后未保存草稿丢弃。调参期间停止主角操作，暂停本插件的动作时序；不会设置全局 `Time.timeScale`。
- 在游戏运行期间手动修改配置文件后，点击“从配置文件重载”。保存和重载会显示实际闪避参数，并记录配置路径及变更值；下一次动作使用新值。
- **F7**：开关闪避方向与动作时序调试；不再增加扇形绘制，也不覆盖常规攻击范围开关。
- 警察前摇默认显示红色命中扇形，不依赖 F7；可通过 Capture / ShowAttackRange 关闭。范围按地面高度绘制，带半透明填充。
- 常规反馈：警察抓捕前摇显示红色菲涅尔；主角普通闪避显示稳定的白色菲涅尔，跟随动画至 0.55 s；完美闪避成功切换参考粉色 RGB (255, 102, 182)，持续 0.30 s。自然结束前最后 0.08 s 平滑回到原材质的颜色与边缘形状，不再使用亮度脉冲。使用角色原材质 lilToon 的 GPU 菲涅尔，在原绘制表面内叠加并保留透明裁剪。材质副本按角色复用；结束恢复原材质，同时清理实例化副本及缓存中的特效参数，防止效果常驻。取消和结果流程立即清理。详见 [生命周期修复](docs/0.1.8菲涅尔生命周期与颜色同步.md) 与 [0.1.9 稳定显示及参考粉色](docs/0.1.9菲涅尔稳定显示与参考粉色.md)。

DLL 部署至 `BepInEx/plugins/LilliaChasePrototype.dll`。配置位于 `BepInEx/config/local.lillia.chaseprototype.cfg`。插件 GUID / Harmony ID 为 `local.lillia.chaseprototype`。

如同时使用 System 的 F2 界面，调参前先关闭 F2 界面；其现有鼠标悬停逻辑会重置输入轴，可能影响同时打开的其他界面。System 的功能和原配置保留。

## 规则和初始参数

| 动作 | 参数 |
| --- | --- |
| 出刀选择 | 每轮预选轻／重刀各 50%，等待对应距离；启动角 120°、可行动、无遮挡 |
| 轻刀 | 启动 1.4 m；前摇 0.30 s；跟踪到 0.295 s，900°/s；全程按正常警察跑速前进 |
| 重刀 | 启动 2.6 m；前摇 0.60 s；全程 360°/s 跟踪，以正常警察跑速 1.2 倍前进 |
| 抓捕命中 | 两种刀均 1.5 m、完整角 100°，高度差不超过 1.2 m；前摇结束一次判定 |
| 扑空 | 原地固定最终朝向 1.50 s，再间隔 0.10 s 才能预选下一刀 |
| 闪避 | 消耗 25 点；无启动延迟；以缩放后实际跑速的 2 倍突进 0.30 s |
| 闪避恢复 | 0.60 s，水平移速由 0 线性恢复到正常速度；不能提前连闪 |
| 完美窗口 | 起手 [0, 0.10 s)，一次有效接触保护；返还成本并跳过自身后摇；警察仍后摇 1.50 s |
| 跑动动画 | 从闪避开始共播放 0.55 s（突进 0.30 s＋恢复前 0.25 s）；完美结束、取消与结果会提前释放 |

当前参数对应模拟器候选，不表示最终平衡完成。普通完整周期 0.90 s，理想直线跑动位移为 `缩放后跑速×(2×0.30 + 0.5×0.60)`；碰撞会缩短实际位移。

前摇结束立即进行一次真实位置、锁定朝向和遮挡检查，再调用原生失败入口。普通位置避开不会消耗完美保护，多警察各自判定；同一次闪避只能保护一个实例，同一场次只能触发一次 Arrest。

闪避方向锁定，镜头变化不改变路线；通过原生 KinematicCharacterMotor 处理碰撞、坡面和垂直运动。撞墙不会提前结束恢复。突进速度按 `原生实际跑速×已加载 System 的全局跑步倍率×Dodge.RunSpeedMultiplier` 计算；全局倍率只计一次，无 System 时为 1。恢复期间有输入才移动；跑动动画继续时按真实走／跑根位移与全局倍率计算输入速度，释放动画后在原生正常速度上应用恢复曲线。启动与突进只收取固定闪避成本，临时屏蔽普通跑动扣费和步行恢复，保留原生耗尽检查；恢复后正常体力规则继续生效。

闪避前 0.55 s 临时播放主角原生 `Run` 片段，沿用正常跑步动画速率，不根据闪避移速加速。没有全局缩放时为原速；有 System 时沿用其全局跑步动画规则 `max(1, 全局跑步倍率/2)`，例如全局倍率 1、2 时均为原速，3 时为 1.5 倍。闪避倍率只改变位移；不修改共享 `Animator.speed` 或原控制器。到达动画时限、动作结束、取消和结果流程释放临时播放图，恢复原生动画。

跑动中起闪继承当前跑动循环进度；动画正常结束且仍有跑动输入时，将原生 `Run` 状态定位到同一循环进度，减少帧数不齐造成的姿态跳变。实测状态位于第 1 层 `Walk`。走动、停步和取消时按原生逻辑恢复。见 [0.1.5 可视化与动画衔接验证](docs/0.1.5攻击范围可视化与跑动衔接.md)。

用于计算位移的原生跑速仍通过不含脚本、碰撞或渲染的骨骼副本采样并缓存，以计入人形重定向和模型缩放。当前走动 3 倍后的实际速度约 2.46 m/s、跑动 1.5 倍后约 4.71 m/s，闪避约 9.43 m/s。跑动默认值与本地配置均为 1.5；模拟器当前使用全局 2 倍基线，实际走／跑速度与本地游戏配置存在差异。详见 [0.1.4 同步与实测](docs/0.1.4轻重刀与闪避同步.md)。

System 插件源码位于此仓库之外；本轮将其跑动默认倍率改为 1.5 的改动另存为 [独立源码补丁](patches/LilliaSystem-run-default-1.5.patch)。在对应 System 源码根目录执行 `git apply --unidiff-zero <补丁的绝对路径>` 后重新构建即可复现。补丁不覆盖已有配置中的跑速值。

菜单、暂停、文本输入、改键捕获、失焦、移动禁止和结果流程拒绝闪避。调参面板使用独立 Canvas，并管理自己的光标与输入锁。活动动作使用开始时的参数快照，修改在下一次动作生效。

## 参数分组与诊断

共有 28 项、6 组：General（模块与按键）、Dodge（闪避及动画时长）、Capture（轻刀启动、共用命中范围、后摇、范围显示和追击速度）、Heavy（概率、重刀启动范围、前摇、转向和移速）、Debug、Logging。固定光效和技术参数继续留在脚本中。

窗口从突进开始计算，按 `PerfectWindowSeconds` 截断在突进结束处，时长 0 关闭。重刀启动范围可以大于命中范围。已有配置保留已保存数值；需要对齐新默认时可用 F6“恢复默认值”。本次本地部署已同步玩法数值，旧配置和 DLL 备份于 `artifacts/before-0.1.4/`。

常规追击速度采用 `主角缩放后实际跑速×Capture.ChaseSpeedRatio`，倍率默认及当前本地配置均为 1.1（当前玩家跑速基线下约 5.19 m/s）。轻刀沿用此速度，重刀再乘 `Heavy.MoveSpeedScale`，当前约 6.22 m/s。追击中导航只负责路径与速度上限，角色位置由动画根位移单独驱动，避免两者叠加；离开追击或进入抓捕时恢复原位置更新设置。详见 [0.1.7 速度与起手性能修复](docs/0.1.7追击速度与抓捕起手性能修复.md)。

完美闪避只在攻击结算时实际处于命中范围、无遮挡且闪避窗口有效时触发。提前冲出攻击范围是普通躲开。成功会完成剩余突进，然后跳过恢复期；不会立即截断突进。判定日志新增 `perfect-reason`、闪避阶段和时间窗口。详见 [0.1.6 判定、边缘光与追击速度](docs/0.1.6完美闪避诊断与边缘光.md)。

警察前摇播放原生 `MCU_am_Loco_Run_01`，用导航与胶囊碰撞推进，禁用动画根位移防止重复移动；后摇释放动画图并冻结完整姿态，结束恢复原设置。没有专用抓捕／扑空动画时仍使用跑动、红光和僵直反馈。轻刀失去攻击视野／被遮挡后停止跟踪；重刀仅朝最后目击位置修正。未同步模拟器的完整搜索和视野状态机。

日志在 `BepInEx/LogOutput.log`，来源 `Lillia Chase Prototype`：

- `[Hook]` / `[Boot]`：是否成功接入原生方法。
- `[Dodge #编号]`：拒绝原因、体力前后值、方向、阶段、结束原因和实际位移。
- `[Capture #编号]`：启动、承诺、判定时距离／角度／高度、遮挡与完美保护、扑空及清理。
- `[Arrest #编号]`：一次原生结果调用。
- `[Animation]`：真实控制器片段清单、候选状态和弃用原因。
- `[Config]`：迁移、修改的键和值、实际闪避参数、磁盘重载、拒绝保存原因。
- `[Visual]` / `[Panel]` / `[Runtime]`：渲染或状态异常及降级原因。

未开始抓捕时，打开 `Logging/Verbose` 查看 `not-chasing`、`target-is-not-player`、`police-unavailable`、`outside-start-sector`、`occluded` 等限频原因。关键运行异常会停用模块并恢复原生抓捕，需查看日志后重启。

## 构建、检查和回退

远程仅编辑、编译、规则检查时，不需要游戏数据目录或游戏 EXE；需要 .NET SDK 与本游戏版本对应的开发引用包。已在游戏目录外验证最小引用环境，准备方式和路径配置见 [远程开发依赖与构建](docs/远程开发依赖与构建.md)。

在游戏根目录执行：

```powershell
dotnet build MyLilliaMods/src/LilliaChasePrototype/LilliaChasePrototype.csproj -c Release
dotnet run --project MyLilliaMods/tests/RulesChecks/RulesChecks.csproj -c Release
./MyLilliaMods/tools/Test-Runtime.ps1
./MyLilliaMods/tools/Test-Runtime.ps1 -WithoutSystem
```

运行时脚本要求先退出游戏；静音运行，隔离原生失败结果，不保存存档，自动退出并删除临时测试 DLL。`-WithoutSystem` 临时移出 System DLL，结束时在 `finally` 中恢复。日志和截图输出到忽略版本控制的 `artifacts/`。

当前验证覆盖真实三类预制体、真实原生入口、实际角色位移与碰撞、前摇转向、扑空恢复、单次完美与多警察结果去重、异常恢复、参数快照、配置重载、原生 UI 按钮监听和实际渲染。完整关卡的实体键盘操作、任务交互与最终平衡仍需游玩验证，见 [实现与验证记录](docs/首版抓捕闪避实现与验证.md)。

退出游戏后移出 `LilliaChasePrototype.dll` 即回退；也可在面板关闭 `CaptureEnabled` 恢复原生近距抓捕，关闭 `DodgeEnabled` 禁用闪避。下一次替换已有发布 DLL 前，先将同名文件备份到 `artifacts/backups/`。
