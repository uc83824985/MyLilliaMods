历史记录：0.1.3 按用户要求取消了闪避移速对动画播放速率的影响，并将抓捕前摇改为 0.3 秒。最新行为见 [0.1.3 调整记录](0.1.3原速跑步与抓捕前摇.md)。

日期：2026-10-13。独立插件升级为 0.1.2。按用户要求更新源码默认值及当前游戏配置：

| 参数 | 新值 |
| --- | --- |
| StaminaCost | 50 |
| DashSeconds | 0.30 s |
| RecoverySeconds | 0.60 s |
| RecoverySpeedScale | 0.10，可继续调整 |

原 `Dodge.Speed` 为绝对米／秒值，现移除并替换为 `Dodge.RunSpeedMultiplier`，不把旧值 10 直接转换成 10 倍。本次明确要求的新默认值也应用到现有配置；其他玩法参数保留。旧 DLL、配置和日志在 `artifacts/before-0.1.2/`。

## 跑速与全局缩放

主角真实预制体：`Assets/00. PakoneSoft/Prefabs/MainChar/Ingame_heroine_prefab.prefab`。其 `MainChar_Animator` 有循环 `Run` 片段，且没有动画事件。

`MaxRunSpeed=3.5` 与 `Run.averageSpeed≈3.812` 均不完全代表当前骨架的原生跑动速度。通过只复制 Transform 骨骼、复制 Avatar、以单倍速评估一个完整 Run 周期，采样实际根位移约 **3.143 m/s**。副本没有角色脚本、碰撞或渲染，避免触发角色生命周期或游戏结果；结果按 Avatar、片段、模型缩放缓存。

可选兼容通过 BepInEx 当前已加载插件的公开 Config 读取 `com.yourname.lilliasystem` 的 `Movement.RunSpeedMultiplier`；不读取 System 内部状态机、不调用 System 方法、不引用其程序集。不加载 System 时使用 1；读取实时值，因此其面板修改在下一次闪避生效。活动动作继续沿用起始快照。

最终突进速度为 `采样的原生跑速×全局跑步倍率×闪避跑速倍率`。主角最终速度后置覆盖，确保全局倍率只计算一次。当前全局倍率 2、闪避倍率 2 时，目标速度约 12.57 m/s。

## 临时跑步动画

突进开始时创建独立 PlayableGraph，播放原生 Run 片段，速率为 `最终突进速度÷采样的原生跑速`。例如全局 2、闪避 2，对应片段速率 4。图直接控制片段时间，不修改共享 `Animator.speed`、控制器或持久字段，避免和 System 的原生动画倍速重复叠加。

后摇开始、取消、模块停用、角色／场景变化和结果流程销毁图，并清除尚未消费的突进根运动，恢复原生动画。调参面板暂停时，图时间也暂停。后摇移动仍按原生／全局缩放后正常速度乘 `RecoverySpeedScale`，默认 0.1。

找不到兼容片段或播放失败时记录降级原因，保留闪避位移；采样失败使用原生跑速字段回退。

## 验证

Release 编译零警告、零错误；15 项规则检查通过。带 System 的 129 项、无 System 的 114 项运行时检查通过，日志分别在 `artifacts/runtime-with-system.log` 和 `artifacts/runtime-without-system.log`。部署 DLL 与 Release 产物哈希一致，临时测试 DLL 已移除，System DLL 哈希保持不变。

新增真实主角预制体检查。原生速度方法的测量值在全局 2 时约 6.287 m/s，采样计算值约 6.285 m/s；二者一致，未使用名义速度字段代替实际跑动速度。

带 System 检查全局倍率 0、1、2、3，突进和片段速率均只乘一次。强制 `Animator.speed` 为 1 与 3 时，临时图的根运动速率一致，验证没有动画倍率叠加。验证后摇恢复、取消释放，以及原有抓捕、体力、配置保存、扇形和 UI 检查。无 System 环境验证独立加载和倍率回退。

检查不修改用户的全局跑步配置；临时配置值和自动保存状态在 finally 中恢复。完整关卡的实际按键与追逃平衡继续由游玩验证。
