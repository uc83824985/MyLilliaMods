# 0.1.3 原速跑步与抓捕前摇

按用户要求，突进临时播放原生 Run 动画，但取消 `突进速度÷原生跑速` 的动画速率计算。闪避移速倍率继续控制物理位移，默认是全局缩放后实际跑速的 2 倍。

动画默认原速，仅沿用现有 System 全局跑步动画缩放规则 `max(1, 全局跑步倍率/2)`：全局 1 或 2 时原速，3 时 1.5 倍；不加载 System 时原速。不将全局位移倍率直接当作动画倍率，也不重复叠加共享 Animator.speed。后摇、取消和结果流程仍释放临时播放图，恢复原生动画。

`Capture.WindupSeconds` 的源码默认值与当前配置均改为 0.3 秒。承诺起点仍为 `min(0.2 秒, 前摇/2)`，因此本次默认 0.15 秒锁定抓捕方向。其他玩法参数继续沿用现有配置。

修改前 DLL、配置和游玩日志备份到 `artifacts/before-0.1.3/`。运行时检查验证不同全局倍率的正常动画速率、更改闪避位移倍率不改变动画速率、正常恢复与取消、0.3 秒抓捕前摇和参数快照，并继续检查原有功能。详见 `artifacts/runtime-with-system.log` 与 `artifacts/runtime-without-system.log`。

Release 编译零警告、零错误；带 System 的 131 项、无 System 的 116 项运行检查及 15 项规则检查通过。部署 DLL 与编译产物一致，临时测试 DLL 已移除。
