# 0.1.4 轻重刀、闪避与完美粉色闪光

游戏侧同步 `sim/chase-lab/dist/presets.mjs` 当前 `rhythm-mixed` 的攻击和闪避规则。模拟器搜索、疲劳、隐身等独立系统不在此次移植范围。

## 当前动作

| 参数 | 轻刀 | 重刀 |
| --- | --- | --- |
| 每轮预选概率 | 50% | 50% |
| 启动距离／完整角 | 1.4 m／120° | 2.6 m／120° |
| 前摇 | 0.30 s | 0.60 s |
| 朝向跟踪 | 至 0.295 s，900°/s | 全程，360°/s |
| 前摇移动 | 正常警察跑速 | 正常警察跑速×1.2 |
| 命中范围 | 1.5 m／100° | 1.5 m／100° |
| 普通／完美落空后摇 | 1.50 s | 1.50 s |

每轮先选刀，再等待对应启动距离，避免处于 1.4–2.6 m 时每帧重选导致重刀占比失真。前摇结束只判定一次；后摇固定最终朝向和位置，结束后间隔 0.10 s 才能选下一刀。启动仍要求原生追逐状态、玩家目标、原生结果回调、可行动且无遮挡。

前摇移动基准为主角实际缩放跑速×1.1，对应模拟器正常警察跑速。以当前全局跑动 2 倍计，轻刀约 6.91 m/s，重刀约 8.30 m/s；抓捕以外仍由原生追逐控制。前摇播放警察原生 `MCU_am_Loco_Run_01`，关闭该时段的动画根位移，防止导航与动画重复移动。使用真实 NavMeshAgent 推进，以最多 0.06 m 的步长检查原生胶囊碰撞和玩家身体接触；碰撞尺寸沿用游戏原生尺寸。无可用导航面时不会直接改坐标强行穿行。

轻刀失去 120°攻击视野或受到遮挡后停止跟踪；重刀只向最后目击位置修正。未移植完整追逐视野和搜索状态机。当前原生警察控制器没有兼容的专用抓捕／扑空动画，表现采用跑动、前摇红光及落空姿态冻结。

闪避消耗 25 体力，无启动延迟，以实际缩放跑速×2 突进 0.30 s。普通后摇 0.60 s，移动倍率从 0 线性恢复至 1，期间不能再次闪避。完美窗口为起手 `[0, 0.10 s)`，只有有效抓捕接触才消费一次保护，返还本次成本（不超过体力上限），保留剩余突进并跳过自身后摇。警察完美落空仍固定后摇 1.50 s。

跑动动画从闪避开始共播放 0.60 s，覆盖突进和普通恢复前半段；动画速率仍为 `max(1, 全局跑动倍率/2)`，闪避移速倍率不加速动画。完美动作结束、取消和结果会提前释放动画。恢复期间动画只负责可见姿态，实际移动跟随当前走／跑输入，停止输入不会被持续 Run 根位移带动。

## 完美闪光与粒子检查

检查本地 Addressables 目录共 3005 个内部资源 ID，并在游戏运行时成功加载 `Particles/Showcase/Prefabs/fx_sparks`、`fx_fire`、`fx_smoke` 和 `Particles/Fog/Prefabs/Ground Procedural Fog`。这些资源各含一个 ParticleSystem，未附带 MonoBehaviour。真实主角预制体没有附带 ParticleSystem。目录结果保存在 `artifacts/particle-catalog-audit.json`，运行时检查记录在 `artifacts/runtime-with-system.log`。

找到的是火花、火焰、烟和雾，没有确认到现成可直接使用的粉色瞬闪特效，因此按用户指定的兜底方案使用现有蒙皮覆盖：普通闪避保持白色，成功保护真实抓捕后立即变为粉色 `(1, 0.25, 0.65)`，按原闪烁频率显示 0.30 s。闪光计时独立于完美缩短的动作，动作提前结束仍继续显示；暂停冻结，取消、停用、场景变化及抓捕结果立即清理。未改动原始角色材质。

## 真实移速

通过真实主角预制体、单倍速走／跑片段及原生 `CharacterController.UpdateVelocity` 验证，平地稳定移动约为：

| 模式 | 原生根位移速度 | 当前全局倍率 | 缩放后实际速度 |
| --- | --- | --- | --- |
| 走动 | 0.820 m/s | 3 | 2.46 m/s |
| 跑动 | 3.143 m/s | 2 | 6.29 m/s |
| 闪避突进 | 缩放后跑速 | 2 | 12.57 m/s |

`MaxWalkSpeed=2`、`MaxRunSpeed=3.5` 是字段值，不能直接乘倍率当作当前地面实际移速。走动原生方法实测 2.4622 m/s，完整片段根位移估算 0.8197×3≈2.4591 m/s；跑动片段估算 3.1426×2≈6.2852 m/s。微小差异来自周期采样及初始帧，不代表额外倍率。

模拟器固定跑速 6.286 m/s，与游戏跑速吻合；模拟器步行设为跑速一半，即 3.143 m/s，比游戏当前走动约快 28%。本次确认并记录该差异，没有将游戏步行倍率从用户指定的 3 倍另行提高。

## 跑动默认倍率调整：1.5

随后按用户要求，将 System 的 `Movement.RunSpeedMultiplier` 源码默认值及本地配置均改为 1.5，并重新编译部署 `LilliaSystem.dll`。默认值变更位于游戏目录下 `.codex/LilliaSystem/src/ItemSpawnMod/MovementScaling.cs`，不属于本仓库的独立追逐插件源码。新建配置与无效参数回退采用 1.5，已有有效配置仍由用户自行设置。本地走动倍率保持 3。

当前跑动约 `3.1426×1.5=4.71 m/s`，约为当前走速 2.46 m/s 的 1.92 倍；闪避约 9.43 m/s，轻／重刀推进约 5.19／6.22 m/s。上面的全局 2 倍实测表是调整前记录；模拟器全局 2 倍基线与现在本地配置有差异。

修改前 System DLL、配置和相关源码备份于 `artifacts/run-speed-1.5-时间戳/`。System Release 编译零警告、零错误，现有独立检查通过；带 System 的追逐运行检查通过，部署 DLL 哈希一致。
