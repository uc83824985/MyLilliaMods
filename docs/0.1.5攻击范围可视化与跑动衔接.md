# 0.1.5 攻击范围可视化与跑动衔接

2026-10-14，本地构建并部署。

## 范围为何没有显示

此前扇形只在 F7 调试可视化开启且存在抓捕动作时绘制。本地 `Debug.ShowGeometry=false`，因此正常游玩没有攻击范围。旧截图能显示调试线，尚无证据表明着色器完全失效；旧检查只确认截图文件生成，也不能证明实景地面上可见。

新增 `Capture.ShowAttackRange=true`：前摇期间显示红色命中扇形轮廓和半透明填充，独立于 F7。F7 仍增加黄色启动范围、青色方向和调试信息。普通范围在扑空后摇隐藏。

原先固定在角色根节点上方绘制；现在逐点探测地面并抬高 0.08 m，排除角色碰撞体，线宽增加到 0.045 m。地面遮挡属于额外防护，未认定为此前不显示的已证实原因。

## 闪避动画

默认值和当前配置的 `AnimationSeconds` 均为 0.55 s。只调整视觉播放时长；本地用户设置的闪避体力成本 0、恢复时长 1 s 保留。

起闪时若正在跑动，读取当前原生 Run 的循环进度；临时动画从该位置播放。结束时若仍有移动输入、正在跑动且允许移动，将原生 Run 定位到临时动画的结束进度，再恢复控制器。使用归一化循环时间定位，相当于按片段长度换算播放帧数。实际主角 Run 状态在第 1 层 Walk，而非第 0 层。

玩家动画开始时进行零时间求值，避免跳过的循环部分被误记为首帧根位移。NPC 动画不进行这一步，保持原有捕获／冻结姿态时机。走动、停步、取消和结果流程不强制跳到跑动状态。
