## 实际游玩日志的结论

窗口改为 0.3 s 后并非完全失效：抓捕 #5、#11 分别在闪避经过 0.101 s、0.096 s 时成功。其他结算距离为 2.237、1.565、1.525、2.418 m 的实例超过了 1.5 m 命中半径，不触发完美保护。重刀还有结算前闪避已进入恢复阶段的情况。

成功的闪避 #12 在 0.306 s 回到 Ready，跳过本地配置的 1 s 恢复；规则是完成剩余突进后取消恢复，不是成功瞬间结束前冲。该次实际位移仅 0.138 m，日志不能独立确认被哪个物体阻挡。没有移动输入、前冲受阻、当前体力成本为 0 等因素都会降低体感差异。

本次不扩大判定区域，也不把普通躲开改为完美。新增逐次原因日志：success、outside-hit-sector、occluded、already-consumed、not-dashing、outside-time-window；记录实际闪避阶段、时间和窗口。成功时额外记录跳过的恢复时长和剩余前冲时间。

## 光效与验证边界

旧粉色与普通覆盖共用亮度放大：最高 RGB 为 (3, 0.75, 1.95)，存在截断、色彩变浅的问题。此前自动检查只读材质颜色，不能证明实景粉色可辨；无法仅凭日志断定用户看到不到粉色的唯一原因。

按本次要求，白、红、粉统一改为菲涅尔近似边缘效果。逐个蒙皮网格烘焙当前法线，以 `(1-abs(N·V))³` 控制顶点透明度；正面淡出，掠视轮廓保留。色值保持在显示范围，普通覆盖透明度上限 0.45，粉色上限 0.55，粉色为 (1, 0.12, 0.55)，持续 0.30 s。源网格与原材质保持独立，覆盖层继承源物体渲染层。

这是 CPU 顶点近似，非新编译的 GPU 菲涅尔着色器；角度权重最多每秒更新 30 次，骨骼动画仍正常更新。采用本游戏角色的均匀缩放假设。测试检查正面／轮廓顶点透明度分布，并渲染真实主角预制体做粉色像素检查。隔离预制体未执行完整服装装配，截图可见部分主要为头部，因此不能替代完整关卡中的整体观感检查。

## 追击与调试

`Capture.ChaseSpeedRatio` 默认 1.1，可通过 F6 修改。常规追击以及轻刀以玩家实际跑速乘此倍率计算，重刀再乘重刀倍率。玩家实际跑速仍由真实 Run 根位移采样并乘全局缩放；当前约 4.71 m/s，因此常规追击约 5.19 m/s。

追击同时设置导航速度上限与跑动动画速率，补偿 System 已有的水平步幅缩放，避免全局倍率重复计算。停止追击、外部暂停、进入抓捕和模块重置时释放覆盖。三种警察均检查配置更新、恢复和真实动画根位移；测试夹具目标速度为 6.60 m/s，带 System 的实际采样约 6.574／6.590／6.574 m/s。

F7 不再绘制额外启动扇形和方向射线；`Capture.ShowAttackRange` 单独控制前摇红色命中范围，关闭时 F7 不会重新显示范围。

部署前日志、配置和 DLL 保存在 `artifacts/before-0.1.6-*`。运行时日志及 `perfect-pink.png` 位于 `artifacts/`。当前用户的成本、恢复时间、完美窗口及全局跑速设置保留。
