# 0.1.7 追击速度与抓捕起手性能修复

## 追击接近两倍目标速度

0.1.6 同时启用了 NavMeshAgent.updatePosition 和动画根位移；此前只采样动画步幅，未测连续 Unity 帧里的最终位移。新增真实帧测试后复现：目标 6.00 m/s，旧双位置更新方式约 11.38–11.79 m/s；修复后约 5.85–5.96 m/s。无 System 时目标 4.00 m/s，旧方式约 7.70 m/s，修复后约 3.92 m/s。测试使用独立导航面、真实警察预制体及已安装 System 的实际根位移组件，夹具速度不是当前主角的真实跑速。

修复为：追击时有根位移的角色关闭导航自动写入位置，导航继续提供路径与速度上限；用角色实际位置同步导航位置。结束追击、外部暂停、进入抓捕和模块重置恢复原 updatePosition 设置。无根位移时恢复导航位置更新。

玩家原生跑速约 3.143 m/s、全局倍率 1.5，当前实际跑速约 4.714 m/s。默认追击倍率仍为 1.1。用户当前配置文件为 1.0，本次保留，因此当前追击目标约 4.714 m/s；若设 1.1 则约 5.185 m/s。

## 抓捕起手开销

根位移缓存原键包含未经量化的 lossyScale，角色旋转产生浮点微差就会导致缓存失效。实际游玩日志反复采样同一角色；旋转回归检查发现同一比例出现 6 个精确浮点缩放值。每次失效都会新建整套骨骼并多次求值动画。现在缩放键量化至 0.0001，旋转测试新增采样次数为 0。

角色注册时预热采样和效果材质；后续抓捕复用同一角色的 Presentation。光效从复制蒙皮网格、30 Hz BakeMesh 和 CPU 顶点菲涅尔改为原材质 GPU 菲涅尔，消除了这部分网格创建、逐顶点计算和烘焙开销。攻击范围地面探测改用复用缓冲区的 RaycastNonAlloc。

这些验证确定了具体开销来源和消除结果；未将隔离场景测试解读为完整关卡的帧率保证。

## 原表面 Overlay

旧实现虽然增加了边缘透明度，仍沿法线外扩 0.018，因此形成截图中的膨胀描边。这是实现遗漏。

实际角色材质使用 lilToon，并包含原生 _UseRim、_RimColor、_RimFresnelPower 等参数。现在为原 Renderer 创建可复用的材质副本，启用原生 GPU 菲涅尔、普通混合、透明度跟随。保留原材质的贴图、透明裁剪及其余设置，不新增 Renderer、复制或外扩网格。效果结束恢复原材质引用；换装或源材质改变时重建副本；场景／模块重置销毁副本。不支持原生 Rim 的材质保留原样并记录诊断。

实际渲染确认粉色边缘可见，截图为 artifacts/perfect-pink.png；隔离主角预制体没有完整服装装配，因此截图主要显示头部。增加原材质引用恢复、连续闪避复用以及不存在外扩 Shell 的检查。

部署前备份位于 artifacts/before-0.1.7-*。未改动当前用户的闪避成本、0.15 s 完美窗口、0.6 s 恢复或追击倍率设置。

最终验证：Release 构建零警告／错误；19 项规则检查通过；带 System 的 225 项、不带 System 的 198 项运行时检查通过。部署 DLL 与 Release 产物哈希一致；临时测试插件已清理，System DLL 已恢复。
