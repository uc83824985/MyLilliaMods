# 0.1.8 菲涅尔生命周期与颜色同步

## 常驻原因与复现

此前清理只在 Renderer 当前材质与插件副本引用完全相等时恢复原材质。原生逻辑或其他模块对材质再次实例化后，引用不同，旧清理会漏掉副本。与此同时，缓存的插件材质仍保留特效参数，被其他逻辑挂回后可重新显现。

新增实际材质复制场景的测试，旧代码确实失败：结束后复制品的边缘阈值仍为 0.15、颜色仍为白色；原材质边缘阈值为 0.25、颜色为 (1, 0.251, 0.435, 0.45)。只检查 _UseRim 不足以发现问题，因为原材质本来就启用 Rim。必须恢复动作前的完整相关参数。

修复为每组特效材质设置独立名称标识，识别由它实例化的副本。原副本恢复原材质引用；游戏拥有的实例化副本在原处恢复 Rim 参数、颜色和纹理，保留其他游戏修改。缓存副本同步恢复原参数，避免重新挂回后再次显示特效。下次动作使用缓存时重新启用特效配置。颜色切换同步到当前实例化副本，因此完美成功不再只修改已不在 Renderer 上的缓存材质。

## 显示时机

- 普通闪避：白色，跟随 0.55 s 跑动动画；动作提前结束、取消或结果流程提前清除。
- 抓捕：三类警察的前摇播放红色，前摇结算或取消时清除，不延续到扑空僵直。
- 完美闪避：成功保护实际攻击后切换粉色，独立持续 0.30 s；取消和结果流程立即清除。

继续使用原材质的 GPU 菲涅尔，不复制／外扩角色网格，不重新引入 CPU 烘焙。

## 验证

覆盖普通动画 0.55 s 边界、实例化材质的参数恢复、当前副本由白色切换粉色、缓存材质复用与防止重新挂回后的残留，以及三类警察红色材质。真实渲染截图：artifacts/capture-red-rim.png、artifacts/perfect-pink.png；红色有效像素 38141，粉色有效像素 3503。独立场景缺少完整服装／关卡初始化，截图仅用于渲染检查。

部署前备份位于 artifacts/before-0.1.8-*。本次未调整用户的移动速度、闪避窗口、体力消耗或恢复时长。

最终验证：Release 构建零警告／错误，19 项规则检查、带 System 的 246 项和不带 System 的 213 项运行时检查全部通过。部署 DLL 与构建产物哈希一致，临时测试插件已移除，System DLL 已恢复。
