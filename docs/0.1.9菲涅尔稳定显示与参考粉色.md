# 0.1.9 菲涅尔稳定显示与参考粉色

## 闪烁检查与处理

普通闪避仍保留旧白光的 9 Hz 正弦亮度规则；取绝对值后峰值重复更快，造成主动亮度脉冲。自然结束时又直接恢复原材质，造成额外的亮度／颜色跳变。

在真实角色材质上检查完整动作：进入闪避后逐步推进时序，材质引用和重建计数保持不变，未复现动作期间反复创建材质。Glow 只在起手时检查缓存，SetGlow 和结束清理不创建材质。缓存失配仍可能在下一次动作起手重建，例如换装或源材质被替换；新增 [Visual] rim-material-cache rebuild 日志，方便实玩跟踪这种情况。

删除普通闪避亮度脉冲，稳定阶段使用固定颜色和透明度。自然结束前 0.08 s 用平滑曲线逐步接近原材质的 Rim 颜色、边界、模糊和菲涅尔指数，最后再恢复材质引用，避免从强特效直接切回原外观。原材质自身可能启用 Rim，因此收尾目标是动作前的实际参数，而非统一强制为零。实例化副本参与相同渐变，缓存与副本清理规则继续生效。取消和结果流程立即清除。

## 参考粉色

根据用户截图取 RGB (255, 102, 182)，即 #FF66B6，替换原先 (255, 31, 140) 附近的深粉色。保持既有透明度与原表面 GPU 菲涅尔。最终屏幕颜色受场景光照、材质混合和色彩空间影响，RGB 为特效输入色。

## 检查

验证连续推进的稳定阶段无亮度脉冲、同一材质上的收尾颜色逐步接近原值、0.55 s 时完成恢复且整个动作重建计数不增加，以及完美成功的缓存和实例化副本均使用新粉色。截图仍输出到 artifacts/perfect-pink.png；前摇红色、粉色持续时间、取消清理和速度检查继续通过。
