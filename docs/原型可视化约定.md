# 原型可视化：红光前摇与白光闪避

当前验证阶段只采用两种提示，其余状态暂不增加颜色、轮廓、文字或额外结果特效。

相关规格：[基础闪避](基础闪避设计.md)、[警察行为循环](警察行为循环.md)、[主动技能](追逐玩法扩展设计.md)。

## 1. 警察：红光前摇

- 抓捕前摇开始时显示红光，前摇结束或被取消时熄灭。
- 暂不用不同颜色区分前摇早期与动作承诺。
- 前摇结束后立即进行一次抓捕判定。
- 按此刻的位置、朝向、遮挡及有效闪避/替身结算。
- 命中本体就直接进入失败处理；未命中则挥空并执行后摇。
- 判定时刻、命中结果和后摇均不额外可视化。

## 2. 主角：白光闪避

- 从闪避启动到突进结束，用白光闪烁提示动作持续时间。
- 短暂无敌窗口位于这段动作中，以同一种白光的短暂增强表示其位置。
- 整段白光闪避不等于整段无敌，只有指定的短窗口提供保护。
- 突进结束后停止白光，进入原有的短暂减速恢复。
- 减速恢复、完美成功结果和其他技能状态暂不增加额外显示。

## 3. 同步规则

- 红光、白光与真实动作时序同步，不提前提示随机出手时刻。
- 颜色只改变表现，不改变识别、服装属性或碰撞。
- 动作取消、结束与场次退出时恢复原显示。
- 先用这两种提示验证时机与位移，其他表现后续按需要增加。
