# 白盒追逐模拟框架与当前开发基线

## 最新补充：贴身长压迫与持闪走动反制

增加三个可独立选择的警察模板：`pressure_attack`使用80%轻刀、20%重刀正常出手；`pressure`使用同样的距离估算、延迟与刀型参数，但在0.9m内开始2.5—5秒的等待，持续正常追踪；看到2.5m内的可见闪避后，经200±40ms反应尝试攻击。`pressure_adaptive`额外观察连续0.2秒的慢速移动／静止，再经相同反应延迟恢复攻击，以减少人类走动恢复时白白拖延的损失。反应下限50ms；攻击仍需实际距离、朝向、视野与冷却允许。看见闪避不代表必抓后摇，拉开足够距离仍能恢复并再次应对。

警察决策脚本为`dist/ai-close-pressure.mjs`，输入只有可见性、距离、动作阶段、实际移动速度及时间；不读取人类体力、当前输入或策略名称。慢速判断使用实际位移，因此碰撞造成的慢速也可能被误判，尚未加入独立的步行动画分类。长压迫时限属于本轮压迫进程，短暂丢视野导致重新选择刀型不会重新计时；实际出刀才清空进程。追逐中的警察体力消耗、疲劳、转向与碰撞规则保留，不提供无限贴身能力。

人类增加`guard_walk`：近身2.2m内保留闪避并走动；看到真实出刀后按提前30ms的完美计划应对，保留原反应延迟、时机方差、漏输入与体力／动作门槛。远离时沿用距离回体逻辑，落空后沿用恢复窗口。没有引入额外奖励，也没有将压力自动绑定体力或战况。

前台顶部增加四项“贴身压迫”预设：焦躁先闪、持续跑动目押、持闪走动对固定长压迫、持闪走动对识别慢走后出刀。预设默认fast、给定压力0.5；人类和警察仍可独立切换。新增模板尚未纳入`OPEN_TRAINED`，原有“均衡候选”只代表旧策略库。现有原生数值、体力上限100、跑动耗体10/s、走动回体20/s保持不变。

`node check-close-pressure.mjs`运行3类反应×2档压力×3个人类×3个警察×32个配对种子，共1728局、每局上限40秒；`CLOSE_PRESSURE_SEEDS`可调整每格种子数。输出`artifacts/chase-lab/close-pressure/report.json`和`index.html`。只比较固定策略，未重新求解均衡。fast、压力0.5、每格32局的结果：

| 人类 | 正常出刀：均时／被捕 | 固定长压迫：均时／被捕 | 识别慢走后出刀：均时／被捕 |
| --- | --- | --- | --- |
| 持续跑动目押 | 27.95s／17/32 | 18.91s／30/32 | 18.01s／30/32 |
| 持闪走动 | 24.62s／18/32 | 30.95s／15/32 | 22.48s／23/32 |
| 焦躁预判 | 11.72s／29/32 | 13.22s／31/32 | 13.63s／31/32 |

持续跑动目押者面对固定长压迫，等待时段累计体力净变均值为−46.33；持闪走动者则为+18.41，首次出刀时体力从正常出刀的81.86提高到98.20。识别慢走的警察将对持闪走动者的首次出刀时间从7.54s缩短至5.25s，但首次出刀时人类仍平均97.63体力，因此此处收益主要来自恢复进攻节奏，而非阻止一切恢复。

焦躁预判者的空闪次数从1.16增至1.88次/局，但空闪后摇被抓从21/32降为5/32，低于25体力被抓从12/32升为28/32。长压迫的收益在此更接近消耗资源：整体捕获率略高，平均耗时却更长，不能声称全面优于直接攻击。各格仅32局，仍需扩大独立样本及后续混合策略训练。

新增`pressureSeconds`、`pressureWalkSeconds`、`pressureRunSeconds`、`pressurePlayerStaminaChange`、`pressurePoliceStaminaChange`，只统计已开始贴身等待、目标可见且仍在观察范围内、尚未允许攻击的时段。体力净变包含空闪成本及自动耗尽后走动恢复，属于宿主统计，未提供给警察决策。攻击事件增加当时人类体力快照；首次出刀时间／体力只统计实际出过刀的对局，报告保留`attackGames`分母。抓空闪后摇、低体力被抓比例以全部对局为分母。

152项回归通过，包括慢走识别与反应延迟、视野与距离限制、持闪走动的真实按键门槛、压迫期资源统计、丢视野重选刀型不重置等待。现有专用浏览器的后台标签验证了新增选择、独立切换警察、保留种子、走动净恢复和慢走触发攻击，JS错误0；未依赖截图作数值判断。

## 最新补充：有体力未闪避统计与近身骗闪

默认100体力、20回体、给定压力0不变；增加“骗闪对照 · 焦躁预判”和“骗闪对照 · 提前计划 / 等见红”两个前台预设，使用fast与压力0.5，可和双方均衡候选独立选择框一起比较。普通均衡候选已扩展为19个人类策略、10个警察策略，新增4704局补齐原有按键计划矩阵中的新行列，总计31920局。原有单元和得分不变；压力0训练的候选不能称作各压力下的最优策略。

新增统计口径：

- caughtWithStaminaNoDodge：被捕判定帧体力≥闪避成本，且从本刀开始后没有成功启动闪避；包含先前空闪后摇锁定等情况。
- caughtWithStaminaReadyNoDodge：上述条件再要求被捕帧自身动作ready，用于排除闪避后摇等行动锁定。
- caughtAfterPreemptiveDodge：最近一次闪避发生在警察尚未出刀时，且在该闪避的普通后摇期间被后续攻击命中。
- preemptiveDodges：在警察没有攻击进程时启动闪避的次数，只表示提前输入，不自动判定为错误。

抓捕事件记录stamina、staminaEnough、playerPhase、dodgeSinceAttack、lastDodgeAt与afterPreemptiveDodge。批量诊断在体力足够未闪组内细分行动锁定、主动绕身、漏输入、观察过晚、目标输入时刻过晚、决策间隔或其它资格限制、请求未成功等。后三类为基于日志的诊断，不能从被捕帧体力单独证明此前每帧均有机会闪避。报告提供占全部对局比例和占被捕对局比例，明确分母；“未闪”也不能等同“操作失败”。

警察bait模板：继续使用真实追逐移动、转向与碰撞，在进入攻击可达范围后随机承诺等待0.75—1.6秒。2.5m内、视野内观察到闪避启动/突进后，经过200±40ms反应延迟（最低50ms）才允许尝试攻击；最终仍需满足攻击距离、朝向、冷却、前摇和命中几何。有限等待到期后也可以正常出刀，不必等到人类先闪。没有读取人类隐藏输入、未来动作、随机状态或体力；看不到的闪避不触发识别。早闪方向合适、成功拉开距离时仍可能逃过这一轮。

人类nervous是可独立选择的焦躁倾向模板：在延迟观测中距离<1.6m、未见攻击且闪避可用时，按到期时间决定是否先闪。等待时间使用指数分布，发生率λ=0.3+1.5×给定压力（每秒），每次接近只抽一次，不逐帧抛硬币；远离至2.2m外或见到攻击后重置。给定压力不随时间、体力、受伤、连败自动变化；只是在这一倾向模板中，较高固定压力提高近身久等时先闪的累计概率。观察到真实攻击后仍需反应和操作。该模型系可调实验假设，不代表真人统计或所有AI都会焦躁。

4320局新对照包含3模型×3压力×5人类策略×4警察策略×24配对种子，40秒上限。fast均衡候选在压力0/0.5/1下，“有体力、本刀未闪被捕”占全部对局20.8%/37.5%/55.2%，其中包含主动绕身失败，原因细分保留pressure.json。此固定策略对照不能推断高压力重新优化后的均衡。统计中的未闪增加同时受操作误差、漏输入与观察延迟影响。

骗闪后立即抓后摇不保证高收益：fast、压力0.5、nervous的24种子下，bait仅1局即时抓到普通闪避后摇，其它捕获常来自后续体力压力；直接轻刀同条件反而20局抓到提前闪避后摇。当前bait是博弈选项而非万能上位替代，不能通过强制命中制造优势。后续需比较人类等待见红、正确方向预判、反向闪与屠夫等待时长、反应延迟的针对关系。

可前台复现的样本：preset=open-bait-nervous，seed=2996376793。4.475s提前闪；警察观察后4.5917s起轻刀；4.8917s命中。人类仍33.8体力但处于闪避后摇，计入有体力未闪与前闪后摇被抓，排除ready未闪。单次后台截图与浏览器导出回放核对一致。

最新独立验证上下界差fast/typical/unstable约0.060/0.141/0.102（收益单位），仍是有限库候选；typical泛化差距较大。新旧权重在同批种子上的结果及压力诊断可视化在artifacts/chase-lab/open-duel/index.html。训练矩阵timing-only-game.json保留加骗闪前结果；当前endurance-game.json为扩展结果。146项回归通过，包括不可见闪避不触发识别、可见识别仍需反应、距离不足不出刀、有体力ready/后摇的分类。浏览器检查新增骗闪样本事件与统计。

## 当前迭代：提前按键计划与给定压力

本节按键计划训练随后又扩展了近身压迫与焦躁预判，最新参数和数量以顶部补充为准。

针对种子42仅轻刀第一刀未按出的问题，将计划时机与实际操作误差分开：原计划为前摇结束前50ms（轻刀250ms），新增相对该计划提前30/60/90ms的候选，分别为轻刀220/190/160ms。三种提前量分别附加到目押恢复、近身反闪、反闪+重刀绕身策略，保留原居中策略供训练比较。负向误差可能导致普通闪避，正向误差和观察/决策间隔仍可能导致按晚，不截断误差、不保证必定输入或成功。

收益仍为80%时间+20%躲避，不额外修改计分鼓励某种按键时机；训练自行权衡更早输入、完美收益和存活风险。重新使用24个训练、32个独立验证种子，3模型×18人类×9警察，共27216局，固定压力0、100体力、20回体、40秒时限、暴露0.85。每个模型同时比较新旧双方、仅更新人类、双方均更新，使用同一份新验证矩阵。旧数据备份endurance-before-timing.json与trained-before-timing.mjs；较早体力上限实验仍是旧权重结果，不能解释为新权重的体力评估。

给定压力`duel.pressure`范围0—1，默认0，前台“给定压力”滑块可调。压力0保留基础模型的不确定性，并非零误差。压力本身不根据体力、受伤、连败或警察行为自动变化；本阶段没有设计这些触发机制。当前压力增益为线性相加，JSON的duel.pressureEffects可单独调整：

| 参数 | 压力0→1的附加量 |
| --- | ---: |
| 反应平均延迟 | +80ms |
| 逐次反应标准差 | +25ms |
| 每刀按键时机误差标准差 | +40ms |
| 每刀漏输入概率 | +10个百分点，合计封顶100% |

例如fast在压力0下为140±25ms反应、时机σ25ms、漏输入2%；压力1下为220±50ms、时机σ65ms、漏输入12%。反应仍沿用25—1000ms截断。时机误差与漏输入每刀仅抽一次；漏输入不逐帧重试。系数是可调模拟假设，没有真人校准。压力会使看到攻击更晚、按键更不稳定、偶发漏输入，但不会延长完美窗口或修改双方动作。

默认前台均衡候选在压力0训练，调高压力是在测试固定策略的抗压表现，不能称为该压力下重新优化后的均衡。前台显示有效反应/误差/漏输入参数，以及每刀计划、误差和是否已输入。重载原始预设会载入新训练权重；既有JSON、草稿和回放保留冻结的旧权重，避免暗中改变用户配置。

复现压力对照：运行node check-open-pressure.mjs，比较0/0.5/1三档压力，三种人类模型、原反闪/提前30/提前60/新均衡四种策略，对仅轻刀/混合/耐心近身等权、24配对种子，共2592局；不按各压力重训。`pressure.json`保留逐局与分组数据，`endurance-game.json`记录新训练与旧权重对照，node render-open-duel.mjs生成可视化。指标“被捕且本刀无闪避”包含漏输入、未观察到攻击及主动绕身失败，不能全部归因于计划按晚；压力报告另列主动绕身部分。

已加入回归：压力0保留基础参数；高压力不读取体力/受伤状态；非法压力被拒绝；种子42保留同一51.5ms误差、提前30ms可按出并完美；高压漏输入仍会失败。143项当前测试通过，浏览器检查覆盖压力草稿、提前时机模板、独立警察选择及种子保留。

## 当前可前台复测：双方均衡候选与100—200体力

本节训练权重与体力数据属于提前按键迭代前的阶段记录；当前按键策略以顶部说明及最新报告为准。

默认维持体力100、回体20/秒、跑动消耗10/秒，固定闪避与轻重刀性能不变。空地实验上限40秒，不结算脱身。新增“空地均衡候选 · fast / typical / unstable”三个预设，双方可分别选均衡或固定模板；前台显示本局抽中的人类和警察策略。均衡按每局种子独立抽取双方完整条件策略，策略内部仍逐刀选择与反应，不能理解为每帧重抽动作。AI不读取对方抽中策略。

JSON的duel.mixtures包含humans/playerMixture与hunters/policeMixture，可独立调整权重，采样会归一化；导出参数和回放冻结本轮权重，后续重新训练不改变旧回放。更换种子会重新抽取，接管、视角等用户状态保持。选择下拉框后点击“应用双方AI并重开”；这也会应用当前参数草稿。duel.selection优先于下方通用AI控制选项，玩家接管仍有效。

缺陷模板：警察slow_scan只将扫视角速度改为45°/秒、扫描阶段改为5秒，其余能力不变；fixed_light固定轻刀距离、无估距误差和额外等待；overreach高估距离0.55m并增加误判概率。人类retreat不闪避，distance基本不主动恢复，只保留紧急走动。偏科与可预测性不保证在所有反应档都更弱，模板效果须看对局。慢扫视只影响扫描阶段，视觉重获和真实声音仍可提前结束搜索，不虚构固定失锁奖励。未引入额外重新锁定延迟或地形交互。

两轮训练/验证共31104局。先12训练/20验证种子，再扩大到48训练/48验证种子，3反应模型×9人类×9警察；第二轮两组种子完全独立于第一轮。每个模型先求6×6限制库，再加入近身反闪、重刀绕身、组合及警察缺陷模板扩展9×9。收益重新明确为80%存活时间（40秒归一化）+20%有效躲避（6次封顶），不含脱身收益；因此不能和旧暴露度综合分直接比较。暴露度固定0.85，本轮没有证明其他暴露度最优。样本按种子配对，权重只用训练集拟合。

## 空地30秒与近身对策：当前阶段结论

## 空地双边策略与回体实验（阶段候选）

以下为恢复策略修复前的历史实验，均衡权重和续航结论需要重新训练验证。

目标是给定人类反应/稳定性/暴露度后，在双方有限策略库内求解并用独立种子检验；不能把随机出刀、五五开或训练矩阵小误差直接称为GTO。默认回体仍为20/秒，10/秒只作为对照，不改变既有玩法配置。无建筑/镜子/隐身；500m半边界避免本轮30/90秒轨迹触及场地边缘。保留疲劳、搜索和实体碰撞。

人类三种假设参数：fast反应140±25ms、每次攻击时机误差σ25ms、漏输入2%；typical为230±45ms/σ45ms/5%；unstable为230±85ms/σ75ms/10%。均为实验假设，不是真人统计。时机误差按每次新观察攻击抽样并保持，漏输入不逐帧重试；反应延迟仍有既有25ms截断，方向也有操作误差。六种策略为目押、目押并恢复、提前预判、学习混合、拉距离（只保留紧急回体）与不闪避后撤。预判按重刀最大威胁距离保守应对，不读取下一刀类型。

警察六种策略为固定节奏、轻刀、重刀、混合、耐心近身、激进重刀，改变轻重权重、距离保守程度、估距方差与入范围后等待时间。最终各策略均有非零距离误差；每次准备新一刀抽样并保持，过早出刀仍按真实距离/扇形判定，不用强制miss概率修改命中结果。误估附加距离0.65m、概率4%—12%；一般σ0.12—0.32m。当前速度估计仍依据可见运动数据，尚未完整模拟屠夫玩家的视觉测距和反应链路。

## 寻路与预判诊断（2026-10-14）

本轮固定闪避和双方运动数值，仅修改机器人决策及界面。发现并修正：自身位置被错误地纳入视觉延迟，导致路点过冲；近身后撤覆盖全局路径；路径评分使用直线目标距离而非实际绕行路长；墙前备用方向仍可能受阻；未知出刀时固定2.3m提前闪避，而站定启动距离仅0.85m，造成过早消耗。现在自身状态即时读取，敌人继续使用延迟观察；依据公开速度短期外推，并按接近速度与保守威胁距离决定预判。路径采用实际可通行分段、路线保持与局部避墙，增加转角对照预设及下一路点显示。尚无完整骗转角、反向假动作或警察截击策略。

预判收益不足也有规则原因：普通闪避启动0.04s、突进0.22s×1.6、恢复0.4s×0.35，总周期0.66s位移约3.09m，同期普通跑约4.15m，净少约1.06m（理想直线，无碰撞）。只有突进更快，不能视为持续移动更快；警察普通追逐速度还是主角的1.1倍。提前避开启动范围可能只推迟警察出刀，不触发扑空恢复。完美则成本25返12，自身恢复0.4→0.26s，警察扑空0.48→0.672s，既节约资源又确定获得追逐间隔。

完美演示还受模型影响：预判预设反应220±40ms，完美预设120±15ms；完美AI知道固定0.3s前摇，在看到攻击后以内部时钟排程，没有额外按键时机误差。逐次视觉反应方差不等于真人落点时机方差，不能将AI演示成功率当作真人反应难度。

同种子修正前/后对照各64局，覆盖站定/直线、预判/完美、常规/快速两档，每格8种子；文件为 `artifacts/chase-lab/navigation-before.json` 与 `navigation-after.json`。旧版常规直线对照中预判平均躲过3.875次、完美0.625次，说明“完美始终优于预判”并不成立；旧版快速站定预判0次、完美1.125次。修正后部分组存活率提高，但出现无交锋超时，站定预判有效躲过仍为0，不能宣称预判收益问题已解决。本轮修复实现偏差，后续先真人确认转角与诱导出刀，再调整警察承诺时机或双方收益。

开始／重开合并：对局进行后或结束后点击会重开并运行；暂停／继续独立保留进度。接管高亮与实际控制状态一致，可交还AI。
