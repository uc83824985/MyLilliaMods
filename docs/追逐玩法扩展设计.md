# Lillia 追逐玩法扩展：首版主动技能设计

本文定义首版玩法原型的设计规格，尚未代表已经实现或验证的功能。重点是进关前选择主动技能，以及技能与警察感知、抓捕动作之间的交互。被动天赋后续设计。

本轮主题研究、六类功能轴与技能重合审查见 [技能机制候选与收敛](技能机制候选与收敛.md)。直接魅惑目前推荐收窄为巡逻/搜索招引，以下同步记录这一候选修订。

警察的完整循环、每节点可选行动与抓捕子循环见 [警察行为循环](警察行为循环.md)。

巡逻操作、四种追逐属性包与玩家式决策见 [警察玩家风格与属性](警察玩家风格与属性.md)。技能原型需要分别验证对这些风格的应对效果。

所有技能配置共有的体力突进、短暂完美窗口与恢复代价见 [基础闪避设计](基础闪避设计.md)。基础动作不占入场主动技能栏。

前期按 [原型可视化约定](原型可视化约定.md) 仅显示抓捕前摇红光与主角闪避白光，判定和其他技能状态暂不额外显示。下述技能表现作为后续候选，不作为当前阶段要求。

## 1. 目标

- 让玩家通过位置、时机和信息误导改变追逐结果。
- 提供不同的出门准备方案，让同一地图支持多种脱身方式。
- 普通移动与地形应当能够支持基础脱身；技能增加选择和容错。
- 优先使用角色副本、材质、音效、粒子和现有动作表达，降低新动画需求。

## 2. 入场选择与公共规则

### 2.1 技能配置

- 首版建议提供两个主动技能栏，从四种技能中选择两个不同技能。
- 进入关卡后固定配置，返回准备界面后可更换。
- 第一验证场景开放全部四种技能，不以资源刷取或等级解锁作为测试前提。
- 默认两个按键触发，并允许改键；界面显示技能、剩余次数及当前生效状态。
- 这些规则是原型默认方案，后续根据游玩验证调整。

### 2.2 使用成本

- 第一验证场景中，每个已选技能提供两次使用机会，不在追逐中自动恢复。
- 这个次数只用于小场景验证，完整关卡的次数与恢复方式需要另行评估。
- 两次技能释放之间设短暂公共间隔，避免同一输入瞬间叠加全部效果。
- 没有合法目标、处于禁止施法状态或落点不合法时，不扣次数，并反馈原因。
- 已成功释放但使用情境不利时，正常消耗次数，例如在警察持续注视下生成诱饵。
- 普通道具继续承担自己的用途；技能与道具的恢复、经济关联后续设计。

### 2.3 稳定的技能规则

- 生效条件成立时，技能结果确定；警察行为倾向影响其后续决策。
- 感知判定采用警察视野、遮挡、听觉和目标记忆，不采用玩家镜头朝向。
- 短暂停步、失去视线、失去目标和结束追逐分别处理。
- 技能不直接清除地图警戒或让所有警察同时忘记玩家。

## 3. 技能总览

| 技能 | 主要作用 | 适合的阶段 | 核心决策 |
| --- | --- | --- | --- |
| 幻影替身 | 留下诱饵，或骗过一次已经承诺的抓捕 | 断视线后、近距离抓捕前 | 地点、释放时机与保留资源 |
| 敛息 | 暂时抑制主角产生的移动声音 | 误导后转移、搜索阶段 | 安静行动与拉开距离的取舍 |
| 幻衣伪装 | 改变本体识别特征，提高搜索阶段的隐蔽能力 | 断视线后、普通 NPC 附近 | 避开目击、选择恢复活动的时机 |
| 魅惑招引 | 吸引尚未确认追捕本体的目标转向、接近 | 巡逻、接近、搜索 | 引到何处、怎样绕行、承担识别风险 |

## 4. 幻影替身

### 4.1 普通留影

- 在主角当前地点生成一个短暂存在的幻影，保留释放时的姿态与朝向。
- 初版使用静态或现有待机姿态；复杂的路线重放后续评估。
- 对每名警察分别判断其是否见证了本体与幻影分离。
- 见证分离的警察继续跟踪本体，不因为诱饵生成而强制转移目标。
- 未见证分离、又在最后已知位置附近发现幻影的警察，可以将其当成目标。
- 警察接近或尝试抓捕后识破幻影，随后观望、搜索或调查实际听到的声音。
- 误导结束后看见本体，就恢复追逐；没有发现时，逐渐进入脱身流程。
- 幻影自身不制造额外移动声音，防止首版同时引入声源技能。

### 4.2 精准替身

- 同一个技能在抓捕前摇的关键时机释放，可以保护本体免于一次指定抓捕。
- 前提是警察已经进入动作承诺阶段，但抓捕判定尚未结算。
- 这是一次抓捕目标误判，不要求警察当场失去对本体的整体锁定。
- 该次抓捕命中幻影后落空，警察完成正常的扑空后摇。
- 不额外叠加长时间眩晕，不赋予对所有警察、所有伤害的持续无敌。
- 释放过早时按普通留影处理；释放过晚时不能撤销已结算的抓捕。
- 多警察场景中只处理一个明确的抓捕实例，其他警察仍按各自感知行动。
- 同一次释放触发精准模式后，不额外留下持续诱导的普通分身。

### 4.3 反馈与用途

- 普通留影：半透明角色副本、短音效及淡出。
- 精准成功：幻影破碎和独立成功音效，清楚展示抓捕落空。
- 技能自身不自动结束追逐；玩家利用误导或后摇继续行动。
- 主要取舍：现在用于拐角脱身，还是保留应对下一次抓捕。

## 5. 敛息

- 在一段时间内抑制主角产生的脚步声及其他已明确归类为移动的声音。
- 只改变声音感知，不隐身、不取消已有的视觉锁定。
- 不清除警察已经记住的声源位置；警察仍会调查最后听见的位置。
- 不默认静音道具、环境物体或任务交互，这些声源分别判定。
- 初版对步行、蹲伏、奔跑产生的脚步声都生效，允许玩家在有效期内快速而安静地转移。
- 效果结束后恢复正常声音规则；玩家决定继续奔跑、放慢脚步或进入遮挡。
- 界面持续提示当前声音状态，效果结束有明确反馈。
- 主要取舍：现在消耗技能争取安静转移，还是保留次数并依靠正常移动与地形。

## 6. 幻衣伪装

- 临时改变主角的外观识别特征，表现为幻术衣装或对角、翼等特征的遮蔽。
- 这是识别机制，不要求实际换装，也不改变物品、任务服装条件与原有收益。
- 警察持续看见伪装过程时，仍知道伪装者就是本体。
- 只有先断开视线，伪装才有机会影响后续重新识别。
- 搜索中的警察再次看见伪装本体时，先进入怀疑与确认过程。
- 短距离观察、明显异常行为、抓捕交锋或特定任务交互会使伪装失效或被识破。
- 有效时可以降低重新识别的距离或提高确认所需时间；具体采用哪个参数由原型验证。
- 效果结束后恢复原识别特征；警察仍需要新的有效感知，不能穿墙重新锁定。
- 主要取舍：利用隐蔽窗口恢复日常行动，还是继续冒险完成容易暴露身份的目标。

## 7. 魅惑招引（本轮收窄候选）

- 玩家主动选择一个正面、没有遮挡且能感知主角的巡逻或搜索警察。
- 目标尚未确认追捕本体时，引导其转向并有限度地接近主角所在位置。
- 主角承担被观察、识别和升级为追逐的风险，后续需要断视线或绕行。
- 用于改变任务位置周围的巡逻分布，不提供抓捕打断或立即脱身。
- 已经确认追捕本体的目标不额外响应招引；已结算的抓捕不会被撤销。
- 对摄像头等不具有注意力或心智的设备不生效。
- 对同一警察连续释放不无限延长招引；目标保留此前记忆。
- 只影响一个目标，其他警察不受控制。
- 表现优先使用眼部光效、目标状态特效和转向行为，不要求新增复杂表演。
- 主要取舍：主动吸引注意打开路线，还是等待巡逻变化保持低风险。
- 这项修订用于降低与精准替身的近距离保命功能重合，仍需原型验证。

## 8. 衣服、搜索与追逐加速

- 衣服暴露度影响目标锁定保持、搜索阶段重新识别或相关确认速度。
- 声音提供发生声音的位置，不能持续提供无声移动后的真实位置。
- 持续有效追踪本体时积累追逐加速；短暂丢视线时暂停或延缓积累。
- 真正失去目标、误导后的搜索失败让加速逐步消退。
- 四种技能均不无条件清空追逐加速。
- 静音与伪装分别影响声音和识别，与基础服装共同作用。
- 原型首先固定服装条件验证技能，再加入服装差异，避免同时调整过多变量。

## 9. 必要的基础追逐支持

主动技能发挥作用前，需要具备以下规则：

- 警察抓捕具有清楚的前摇、动作承诺、判定和后摇。
- 在判定时检查实际距离、朝向与遮挡；扑空不能自动吸附本体。
- 警察失去视线后追向最后确认位置，调查声音并观望搜索。
- 每个警察保留本局稳定的行为倾向，在合法动作中按权重选择。
- 警察选定动作后短暂执行，给玩家观察与反应空间。
- 地图至少提供遮挡、岔路和转角；撤离窗口与成功脱身相衔接。
- 玩家耗尽技能后仍有利用基础地形与感知规则脱身的可能。

## 10. 六种配置的预期差异

| 配置 | 预期游玩方式 |
| --- | --- |
| 替身 + 敛息 | 误导后安静转移，兼顾近距离失误补救 |
| 替身 + 伪装 | 脱离确认后改变身份，重新进入目标区域 |
| 替身 + 招引 | 先主动改变巡逻位置，再利用分身误导返回路径 |
| 敛息 + 伪装 | 主动避开交锋，利用搜索阶段隐藏和混入环境 |
| 敛息 + 招引 | 将警察吸引到当前位置，再利用遮挡安静绕行 |
| 伪装 + 招引 | 主动吸引注意，断视线并伪装后重新进入目标区域 |

以上是需要验证的设计预期，不保证所有配置已经平衡。

## 11. 第一验证场景与验收问题

- 一个含遮挡、转角和岔路的小场景，一个任务点、一个撤离点。
- 首轮一名警察；基础技能行为成立后，再验证两名警察的独立感知。
- 固定服装与警察基础参数，分别体验六种配置。
- 无技能配置也要进行对照体验。

需要回答：

1. 玩家能否判断技能为何生效或失效？
2. 替身能否分别支持拐角误导和精准抓捕应对？
3. 静音后，警察是否调查旧声源而非持续追踪真实坐标？
4. 伪装是否保留目击连续性，且能在搜索阶段争取行动空间？
5. 招引是否改变任务周围的巡逻分布，同时保留被识别与追捕的风险？
6. 各配置是否产生不同路线、移动方式和风险选择？
7. 成功脱身后，玩家是否能够完成任务或撤离？
8. 是否存在无限控制、瞬间清警戒或固定配置必选的问题？

## 12. 待实现检查与后续范围

- 检查插件能否接入警察目标选择、视听感知、抓捕判定和追逐状态。
- 检查是否可以安全生成、清理角色副本与特效，修改识别参数并恢复原值。
- 明确任务交互中允许施法的条件、保存退出时技能状态的处理。
- 第一轮不确定持续时间、距离和精准窗口的最终数值；根据实际动作与地图验证后填写。
- 第一轮不加入复杂分身动作重放、自由传送、被动天赋与完整技能经济。
- 本规格不表示已经确认游戏开放相应扩展接口。
